# qFoldIT Rust Boundary

## Status

Canonical qFold scientific engine lineage.

`UEFN-QFOLDIT` / `qfoldit-core` is the runtime and semantic authority. This repository may remain an independent scientific engine where its implementation has independent scientific value.

## Integration rule

qFold execution exposed to qFoldIT MUST cross a versioned Rust adapter contract preserving mission identity, scientific object identity, candidate/result hashes, engine version and provenance.

Scientific results remain subordinate to the approved validator/evidence chain.

## Migration direction

Rust-native qFold implementation is preferred. Any non-Rust execution remains a contained foreign-science boundary until a justified Rust implementation exists.
